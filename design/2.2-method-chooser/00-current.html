What is actually wrong

The prioritisation has never run. :1013 declares priority = ['fel','meme','slac','fubar'] and looks up priority.indexOf(a.id). But a.id is a methodConfig key — 'FEL', 'MEME' — so every lookup returns −1 and the whole branch is dead. Verified by running the real comparator: FEL lands 8th, MEME 11th, SLAC last.
Full names are not differentiators. "Fixed Effects Likelihood" and "Mixed Effects Model of Evolution" are equally opaque to someone who does not already know which to use. The strings that would actually help — shortDescription — exist at :43–147 and render only after selection (:1363).
The one orienting sentence is gated on not having chosen. {#if !selectedMethod} at :1716. It disappears at the exact moment a user might want to reconsider, and never returns.
Four kinds of thing are shown as one kind. A per-site test (FEL), a per-branch test (aBSREL), a gene-wide test (BUSTED), a recombination screen you run before any of them (GARD) and a neural surrogate for one of the others (AxoMEME) are sixteen equal rows in an alphabetical list.
FADE has been "Coming Soon" indefinitely. It is in methodConfig (+page.svelte:137) but not in SUPPORTED_METHODS (:24–40), so it renders permanently disabled. A promise with no date is not a promise.
