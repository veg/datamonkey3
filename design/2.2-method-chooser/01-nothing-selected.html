Which sites are under selection?

Why this shape

A dropdown is the wrong control for this decision. A <select> is a retrieval control: it is right when you know the value you want (genetic code, p‑value). Choosing a method is a comparison among four or five candidates. Comparison needs them all on screen at once. Every other control in this panel stays a <select>; only this one changes, because only this one is a comparison.
The headings are the guidance. No tooltips, no help panel, no per‑method "learn more". The question a user arrives with is printed above the methods that answer it, and — see state 02 — it survives selection. This replaces the hint at :1716 rather than adding to it.
Group order is frequency of the question, not the alphabet. "Which sites" first because it is the question most Datamonkey users arrive with, and because it is what the dead priority array at :1013 was trying to express. Within a group, order is FEL, MEME, FUBAR, SLAC — the intended priority, now actually rendered.
AxoMEME is indented under MEME because it is not a peer of it. It predicts MEME's output; it is not another way to ask the question. The indent is 39 px so its description column still lands on the parent description column — a second alignment axis, not a broken one. Its cost (17 MB) is on the row, because the block that used to state it — :1383–1392, gated on browserOnly — is dead: nothing in methodConfig sets that flag any more, so the download is currently never announced.
GARD gets its own legend because it is not a selection test. It is a screen you run first. Listing it as the tenth of sixteen peers misrepresents the workflow. One line states the consequence of skipping it, which is the single most useful sentence on this screen for a user who does not already know it.
Five methods are collapsed, one is deleted. BGM, PRIME, MULTI‑HIT, NRM and B‑STILL answer questions you do not arrive with by accident; a user who wants PRIME knows the word "PRIME". FADE is removed from the list entirely — leave the methodConfig entry, drop the permanently disabled row.
No method is preselected. +page.svelte:60 sets selectedMethod = 'FEL' and it never reaches this component. Leave it that way. Silently choosing a statistical test for a user is not a convenience; it is a claim about their data that the software cannot make.
Cost: +478 px, in a region that is empty. 563 px against today's 85 px (select + hint). Everything below is gated on {#if selectedMethod}, so before a choice this panel holds nothing else. The space is spent where the decision is, once, and state 02 gives it back.
Keyboard and screen readers. One name across nested <fieldset>s: arrows traverse all fifteen (only one can be chosen), legends are announced on entry. Do not build a listbox.
